Facility photography goes in this folder.

Name each file after its gallery entry id so it is picked up automatically:

    clinic.jpg
    reception.jpg
    waiting-area.jpg
    consultation-room.jpg
    laboratory.jpg
    pharmacy.jpg

Supported formats: .jpg .jpeg .png .webp .avif
Suggested size: 1600px wide or larger, 4:3 aspect ratio.

Until a matching file exists, the gallery shows a designed placeholder.
No other code changes are required.
