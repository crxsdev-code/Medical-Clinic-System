Doctor portraits go in this folder.

Name each file after the doctor's id so it is picked up automatically:

    dr-nikhil-rhoul-s-mendoza.jpg
    dr-nilda-s-mendoza.jpg

Supported formats: .jpg .jpeg .png .webp .avif
Suggested size: 800px wide or larger, portrait orientation (4:5 works best).

Until a matching file exists, a designed placeholder with the doctor's
initials is shown on the card and in the profile modal.
No other code changes are required.
